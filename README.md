# 블록 던전: 시프트의 균열 — 멀티플레이 버전 (최대 4명)

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| `public/index.html` | 게임 본체 (원본 게임 + 멀티플레이 기능) |
| `server.js` | 게임 페이지를 제공하고, 방을 만들어 플레이어끼리 메시지를 주고받게 하는 서버 |
| `package.json`, `package-lock.json` | 서버 실행에 필요한 설정 (`ws` 라이브러리) |
| `render.yaml` | Render 자동 배포 설정. 무료 요금제, 시작 명령, 상태 확인 주소가 모두 들어 있습니다 |

---

## Render에 올리기 (한 번만 하면 됩니다)

설정 파일이 모두 들어 있으니 아래 순서대로 누르기만 하면 됩니다.

1. **GitHub에 올리기**
   - https://github.com 에 로그인 → 오른쪽 위 **+** → **New repository**
   - 이름 예: `block-dungeon-mp` → **Create repository**
   - 만들어진 저장소 화면에서 **uploading an existing file** 을 누르고,
     이 압축 파일을 푼 폴더 안의 **모든 파일과 `public` 폴더**를 끌어다 놓기 → **Commit changes**
     (`render.yaml` 이 저장소 맨 위에 있어야 합니다)

2. **Render에서 배포하기**
   - https://render.com 에 GitHub 계정으로 로그인
   - **New +** → **Blueprint** → 방금 만든 저장소 선택 → **Apply**
   - 몇 분 지나면 `https://block-dungeon-mp-xxxx.onrender.com` 같은 주소가 생깁니다.

3. **친구들에게 그 주소를 보내면 끝!**

> Blueprint 메뉴가 안 보이면: **New +** → **Web Service** → 저장소 선택 →
> Runtime `Node`, Build Command `npm install`, Start Command `node server.js`, Instance Type `Free` 로 만들면 똑같이 동작합니다.

## 게임하는 방법

처음 화면에 버튼이 3개 있습니다.

- **혼자 하기**: 원래 게임과 똑같습니다 (새 모험 / 이어하기).
- **같이 하기**: 방을 만들거나 친구 방에 참가합니다.
- **닉네임 입력**: 다른 플레이어에게 보이는 이름 (최대 12글자). 같이 하기 전에 정해야 합니다.

### 방장 (방 만들기)
- **새 모험으로 방 만들기** 또는 **이어하기로 방 만들기**를 누릅니다.
- 오른쪽 위에 **방 코드 4글자**가 보입니다. 친구에게 알려 주세요.
- **이야기, 의뢰, 던전 진행은 방장의 저장 데이터 기준**입니다. 던전 입장/퇴장, 균열 입장, 장로와의 대화로 이야기를 진행하는 것은 방장이 합니다.
- 방장이 던전에 들어가거나 나오면 참가자들도 자동으로 따라갑니다.

### 참가자 (방 참가)
- 방 코드를 입력하거나 **열린 방** 목록에서 **참가** → 캐릭터를 고르면 방장의 세계로 들어갑니다.
- 참가자의 레벨·장비·에메랄드·인벤토리는 **참가자 본인 브라우저에 따로 저장**되어 다음에 참가할 때도 그대로 이어집니다.
- 처음 참가하면 활과 화살 24발을 줍니다.

### 함께 하는 규칙
- 몬스터는 가장 가까운 플레이어를 노립니다. 함께하는 인원이 많을수록 몬스터 체력이 늘어납니다.
- 몬스터를 처치하면 근처에 있는 **모두가 경험치와 영혼**을 얻고, 전리품은 **각자 따로** 떨어집니다.
- 상자와 감옥은 누가 열든 모두에게 열리고, **보상은 각자 받습니다**.
- 황금 열쇠, 발판, 잠긴 문은 누가 풀든 모두에게 적용됩니다.
- 방장이 의뢰 보상을 받으면 참가자도 함께 보상을 받습니다.
- 지도와 미니맵에 동료 위치가 색깔로 표시되고, 머리 위에 이름과 체력이 보입니다.

## 알아 두면 좋은 점

- **무료 Render 서버는 15분 동안 아무도 접속하지 않으면 잠듭니다.** 다음 첫 접속 때 깨어나는 데 1분 정도 걸리니, 처음 화면이 늦게 뜨면 조금 기다려 주세요.
- 몬스터와 이야기는 **방장의 브라우저가 계산**합니다. 방장이 다른 탭으로 가거나 창을 내리면 세계가 잠시 멈춥니다 (참가자 화면에 안내가 뜹니다). 방장은 인터넷과 컴퓨터가 가장 좋은 사람이 맡는 것이 좋습니다.
- 방장이 나가면 방이 닫히고 참가자는 처음 화면으로 돌아갑니다. 참가자의 캐릭터는 저장되어 있습니다.
- 멀티플레이 중에는 인벤토리·지도 같은 창을 열어도 게임이 멈추지 않습니다. (혼자 하기에서는 예전처럼 멈춥니다.)
- `index.html` 파일을 그냥 더블클릭해서 열면 **혼자 하기만** 됩니다. 같이 하기는 배포한 서버 주소로 접속해야 합니다.

## 내 컴퓨터에서 시험해 보기 (선택)

[Node.js](https://nodejs.org) 를 설치한 뒤 이 폴더에서:

```
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다. 창을 두 개 열면 혼자서도 방장/참가자를 시험해 볼 수 있습니다. (같은 브라우저는 저장 공간을 공유하므로, 참가자는 시크릿 창이나 다른 브라우저로 여세요.)
